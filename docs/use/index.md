# Using cmd

cmd sits behind a hotkey. Press ++option+space++, type, and rows appear as you type; press
++enter++ to act on the one that is selected. What the rows are depends on the plugins you
have: the calculator answers arithmetic, `web` searches the web, `f` finds files, and so
on.

![The launcher, just opened](../assets/screenshots/launcher-empty.png){ width="640" }

!!! note "About the screenshots"
    They come from a Linux build of the app. On a Mac the window is translucent, the text
    is in the system font, and each row has an icon.
