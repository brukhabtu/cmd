# How work moves

Work is on the board in `backlog/` ([Backlog.md](https://backlog.md)): an intent, its
milestones, and tasks with acceptance criteria. Anything bigger than a few steps is sized,
planned on its task, built, and closed by a reviewer who did not build it, against the
criteria and the evidence. Design choices become [decisions](decisions/index.md);
repeated mistakes become [skills](../skills.md), accepted only when an eval shows they
help.

```sh
backlog task list --plain
```
